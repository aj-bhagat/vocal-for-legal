# Launch checklist

- [ ] Replace all advocate, office, email, practice-area, and domain placeholders.
- [ ] Verify every qualification and professional claim with the advocate.
- [ ] Have site content reviewed for applicable Indian law and Bar Council requirements.
- [ ] Review the privacy notice and terms against the actual operator and data handling.
- [ ] Configure SMTP secrets outside source control and test a non-sensitive test enquiry.
- [ ] Confirm the form only reports success after the API confirms email dispatch.
- [ ] Set production CORS origins and HTTPS.
- [ ] Confirm rate limits, logging, error messages, and operational ownership.
- [ ] Replace example.com in `robots.txt`, `sitemap.xml`, and metadata.
- [ ] Add domain to Google Search Console and inspect indexing.
- [ ] Review mobile layout, accessibility, keyboard navigation, and screen-reader status.
- [ ] Do not publish invented qualifications, testimonials, rankings, success rates, guarantees, or unverified practice areas.
